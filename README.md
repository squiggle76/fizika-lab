# ФізикаLab

Незалежний статичний навчальний прототип уроку «Похила площина» українською мовою.

## Публікація на Vercel
1. Створіть репозиторій `fizika-lab` на GitHub.
2. Завантажте `index.html`, `styles.css`, `app.js` до кореня репозиторію.
3. У Vercel імпортуйте цей репозиторій; Framework Preset: Other; Build Command: порожньо; Output Directory: `.`.
4. Натисніть Deploy. Подальші зміни в main можуть запускати автоматичну публікацію.

## Локальний запуск
Відкрийте `index.html` у браузері. Сервер і збірка не потрібні.

## Межі прототипу
- Один урок, 8 тренувальних завдань, наочна модель, характерні кути, формули, перевірка одиниць.
- Прогрес правильних відповідей зберігається у localStorage лише на поточному пристрої.
- Немає авторизації, серверної бази даних, синхронізації або механізму адаптивної діагностики.
- Розширення курсу і педагогічної діагностики — наступні ітерації.
