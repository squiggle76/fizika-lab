# ФізикаLab — підсумкова локальна версія від 21.11.2026

Навчальний веб-сайт українською для учнів від 12 років. У пакеті: 8 тем із короткими статтями, 30 навчальних вправ, обов’язкові вбудовані мікрозадачі, задачі на міркування, 4 діагностичні варіанти (32 завдання) з оригінальними зображеннями й розборами, схема похилої площини з фіксованими кутами та дослідження одиниць і формул без потреби знати синуси/косинуси.

## Особливості оцінювання

- Обов’язкова мікрозадача перед наступною частиною статті. Не можна обійти її переходом до тренування; допускається відповідь «Не знаю», що зараховується як неправильна перша спроба.
- Перша відповідь зберігається. Після помилки доступне пояснення і **дві нові корекційні задачі**, результати яких оцінюються окремо. Не можна виправити початкову оцінку повторним натисканням.
- У контрольних задачах наступне обов’язкове запитання з’являється після завершення попереднього та, за потреби, двох корекційних задач.
- Оригінальна діагностична робота: кожне завдання обов’язкове, відповідь «Не знаю» доступна, перевірка і рішення — після завершення всієї роботи. Письмові відповіді потребують перевірки дорослого.
- Звіт показує перші спроби окремо від корекцій; є експортування JSON.

## ВАЖЛИВО ПРО ЗАХИСТ РЕЗУЛЬТАТІВ

Це **локальний прототип**, без серверної авторизації. Результати зберігаються лише в `localStorage` цього браузера і **не є захищеними від очищення або редагування на пристрої**. В іншому браузері чи на іншому пристрої прогрес не синхронізується. Для надійного батьківського кабінету потрібен сервер з авторизацією та серверною перевіркою. Не вводьте особисті дані дитини.

## Публікація в існуючому GitHub + Vercel

1. Розпакуйте ZIP. **Не завантажуйте сам ZIP** до репозиторію.
2. Відкрийте `https://github.com/squiggle76/fizika-lab`, натисніть Add file → Upload files.
3. Перетягніть усі файли **зсередини** папки, включно з `assets/`. Файл `index.html` має бути в корені репозиторію.
4. Натисніть Commit changes у гілці `main`.
5. Vercel автоматично опублікує новий коміт; дочекайтеся Ready в Deployments.
6. Перезавантажте сайт Ctrl+F5.

Не видаляйте існуючі дані браузера: це може стерти локальний прогрес. Якщо попередня версія вже була використана, спершу експортуйте результати.

## Запуск і структура

Відкрийте `index.html` локально. Це статичний сайт без npm або збірки. `data.js` — уроки і завдання; `diagnostics.js` — діагностичні роботи; `deep-learning.js` — мікрозадачі й поглиблені контрольні; `app.js` — базовий інтерфейс; `upgrade.js` — історія перших спроб; `final-controls.js` — обов’язкове проходження і корекція; `styles.css` — оформлення.

Використовується шкільне наближення g=10 Н/кг (коли не зазначено інакше). Це навчальна версія, а не гарантія офіційного оцінювання.
