# Лабораторія знань 4.5 — готове оновлення для занять

Це **повна** збірка, що замінює 4.4. Не потрібно заливати попередні ZIP.

## Що поліпшено
- Дві гілки: **Фізика** і **Геометрія / коло Ейлера**. Матеріали й оригінальні діагностичні роботи збережені.
- У перших геометричних кроках зменшено дублювання тексту; визначення медіани та висоти залишилися у довіднику, перевіряється **використання**, а не написання назв.
- Формулювання теореми кола Ейлера знаходиться на початку.
- У фізичному тренажері виправлено послідовність обов’язкових завдань: невирішене питання більше не перескакується автоматично через пошук наступного невідповіденого.
- Після відповіді — пояснення; якщо була помилка, дві нові задачі й окремий результат корекції. Перша оцінка не змінюється.
- Кнопка **«↺ Почати з нуля»** у шапці обнуляє **обидва предмети** після двох підтверджень.
- Інтерактивне коло дев’яти точок для гостро-, прямо- і тупокутного трикутників.

## Як оновити сайт
1. Розпакувати ZIP.
2. У `github.com/squiggle76/fizika-lab` → **Add file → Upload files** завантажити *вміст папки*, не ZIP.
3. **Commit changes** до гілки `main`.
4. Дочекатися стану **Ready** у Vercel.
5. Відкрити сайт і натиснути Ctrl+F5.

## Обмеження
- Прогрес зберігається в браузері, а не в захищеному хмарному журналі.
- Вільні письмові докази потребують оцінювання дорослим.
- Автоматично генеровані нові задачі через зовнішню AI-службу не підключені.
- При першій перевірці варто пройти кілька кроків правильно і помилково, перш ніж віддати сайт дитині.
