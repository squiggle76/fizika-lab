# ФізикаLab — інтерактивна фізика для учнів від 12 років

Статичний навчальний сайт українською. Сім характерних положень похилої площини (без тригонометрії у поясненнях), короткі навчальні статті, 30 тренувальних завдань із поясненнями, чотири оригінальні діагностичні варіанти (32 завдання) із рішеннями й фотооригіналами.

## Публікація на GitHub + Vercel

1. Завантажте **всі** файли й папку `assets` до **кореня** репозиторію `squiggle76/fizika-lab` (не завантажуйте ZIP як один файл).
2. На GitHub підтвердьте зміни кнопкою `Commit changes`.
3. Якщо Vercel вже під'єднаний до гілки `main`, він автоматично опублікує нову версію. У Vercel → Deployments перевірте стан `Ready`.
4. Налаштування Vercel: Framework Preset `Other`, Root Directory `./`, без build command.

## Локальний запуск

Відкрийте `index.html` у браузері. Не потрібні npm, сервер, API-ключі або платні сервіси.

## Конфіденційність

Усі результати зберігаються в `localStorage` **тільки в цьому браузері**. Жоден сервер не отримує відповіді дітей. Не вводьте персональні дані. Очищення кешу браузера може видалити результати.

## Вміст

`data.js` — статті та тренування; `diagnostics.js` — 4 роботи; `app.js` — логіка, обчислення, перевірка, збереження; `styles.css` — адаптивний дизайн; `assets/` — фото оригіналів.

Зауваження: самоперевірка письмових теоретичних відповідей виконується за зразком, а не автоматичним аналізом тексту. Пояснення і задачі використовують шкільне наближення g = 10 Н/кг.
