# Лабораторія знань — редакція 4.3 (21.11.2026)

Два предмети: **Фізика** та **Геометрія (коло Ейлера)**. Проміжну редакцію 4.1 встановлювати не потрібно: файли вже об’єднані.

## Що є
- Попередній курс фізики, діагностичні задачі та графічні моделі збережено.
- Геометрія: 16 послідовних кроків від середини відрізка до письмового доведення кола дев’яти точок.
- Малюнок із трьома видами трикутника: гостро-, прямо- та тупокутний. Точки, ортоцентр, висоти й коло перебудовуються.
- Обов’язкова відповідь у кожному кроці: без кнопки пропуску. Перша спроба фіксується.
- Після помилки — пояснення та нові завдання; для ключових обчислювальних навичок створено по 24 варіанти плюс початкові задачі. Це перевірені локальні шаблони, **не ChatGPT-генерація**.
- Дві коректні відповіді поспіль підтверджують відновлення навички; початкова помилка залишається в звіті.
- Після трьох додаткових спроб дозволено рух далі **з позначеною прогалиною**, без фальшивого «засвоєно». Це прибирає безвихідні блокування.
- Для письмового доказу — збереження тексту та ручна перевірка дорослим; автоматичне оцінювання доказів не заявляється.
- Звіт для дорослого та експорт JSON. Прогрес у локальному сховищі браузера, без серверного захисту.

## Оновлення через GitHub / Vercel
1. Розпакувати ZIP.
2. У репозиторії `squiggle76/fizika-lab` обрати Add file → Upload files.
3. Завантажити **всі файли і папку `assets`** у корінь (поряд з `index.html`).
4. Зробити Commit changes у `main`.
5. У Vercel перевірити Deployments → Ready; оновити вкладку Ctrl+F5.

Не завантажуйте тільки ZIP. Не створюйте додаткову вкладену папку навколо index.html.
